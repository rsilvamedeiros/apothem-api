# Backend Docs

**Status:** Foundation / Scaffold
**Project:** APOTHEM AI — `apothem-api`

This folder is for **backend-specific operational notes only**: runbooks, local setup quirks, migration notes, deploy troubleshooting — things tied to this codebase that don't belong in product/architecture documentation.

It does **not** duplicate product, architecture, domain, security, data or API documentation. That documentation is canonical in the sibling `apothem-ai` repository under `docs/` (see `apothem-ai/docs/README.md` for the full map), per [ADR-008](https://github.com/apothem/apothem-ai/blob/main/docs/adr/008-two-repository-split.md). Read `apothem-ai/docs/` before implementing anything here; this folder stays empty until there is a real operational note to put in it.
